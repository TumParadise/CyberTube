# CyberTube

แอป YouTube สำหรับ Android — UI ใหม่ + ระบบเล่นเขียนเอง (Compose + Media3)
ใช้ **NewPipeExtractor เฉพาะ YouTube** เป็นตัวดึงข้อมูล ไม่มีบริการอื่น

## ฟีเจอร์ v0.1
- ค้นหา (พร้อม suggestion) + เลื่อนโหลดต่อ
- เล่นวิดีโอ: เลือกคุณภาพ (รวมวิดีโอ+เสียงแยกสตรีมถึง 1080p+), ความเร็ว, แตะสองครั้งข้าม ±10 วิ, เต็มจอ
- เล่นเบื้องหลัง / เฉพาะเสียง (ปุ่มหูฟัง) พร้อมแจ้งเตือนควบคุมเพลง, มินิเพลเยอร์
- สมัครติดตามช่อง (เก็บในเครื่อง ไม่ต้องล็อกอิน) + ฟีดวิดีโอล่าสุด
- ประวัติการดู

## v0.5.0 — เชื่อมบัญชี Google (ใช้กับ microG ได้) + นำเข้าช่องที่ติดตาม
- ตั้งค่า → "บัญชี YouTube": เชื่อมบัญชีด้วย OAuth Device Code — แอปแสดงรหัส แล้วยืนยันที่ google.com/device ในเบราว์เซอร์ **ไม่พึ่ง Google Play Services / microG เลย** (สิทธิ์อ่านอย่างเดียว)
- ปุ่ม "นำเข้าช่องที่ติดตาม" เพิ่มช่องจากบัญชีเข้าแท็บติดตาม (ไม่ซ้ำของเดิม, สูงสุด 1,000 ช่อง)
- ใส่ Client ID/Secret (ประเภท TVs and Limited Input devices) ในหน้าตั้งค่า — ดู `SETUP_GOOGLE.md`
- Refresh token เก็บใน noBackupFilesDir (ไม่ติดไปกับ auto-backup) ส่วน access token อยู่ในหน่วยความจำเท่านั้น
- แก้: ลิงก์ GitHub ในหน้าตั้งค่าที่เป็นข้อความ placeholder
- ลงนาม APK ด้วยคีย์คงที่ (`app/cybertube-debug.keystore`) ทำให้ build ใหม่อัปเดตทับของเดิมได้ **ติดตั้งครั้งแรกหลังเปลี่ยนคีย์ต้องลบแอปเวอร์ชันเก่าก่อน (ประวัติ/ค่าตั้งค่าในเครื่องจะหาย)**

## v0.4.5 — ระบบเปลี่ยนทีม + โลโก้ใหม่
- ตั้งค่า → "เปลี่ยนทีม (Theme Team)": เลือกทีมเขียวเรืองแสง / ทีมสีน้ำเงินเรืองแสง (แตะการ์ดเพื่อดูตัวอย่างสดทั้งแอป, "ตกลง" เพื่อบันทึก, "ยกเลิก" เพื่อกลับทีมเดิม) จำค่าไว้ตอนเปิดแอปใหม่
- โลโก้ใหม่ทุกจุด: ไอคอนแอป (adaptive + round), ไอคอนแจ้งเตือนเพลง, หน้าค้นหา, หน้าตั้งค่า, ตัวเลือกทีม
- รูปพื้นหลัง 9:16 ใช้เฉพาะหน้าตั้งค่า (สีตามทีมที่เลือก)

## v0.4.5 (แก้บั๊ก)
- แก้: เปลี่ยนคุณภาพ/สลับโหมดเสียงตอนหยุดอยู่ ไม่เล่นเองอีกแล้ว (คงสถานะเล่น/หยุดเดิม)
- แก้: สตรีมสด ดับเบิลแท็ปหรือปุ่ม ±10 วิ ไม่เด้งไปต้นหน้าต่างอีก
- แก้: สตรีมสดกู้ได้หลายครั้ง (วัดความคืบหน้าตามเวลาจริง) และ BEHIND_LIVE_WINDOW กลับไปขอบสดเอง; ปุ่ม "ลองใหม่" ของสตรีมสดเริ่มที่ขอบสด
- แก้: retry อัตโนมัติไม่ถูกบล็อกถาวรเมื่อผู้ใช้เลื่อนถอยหลัง และรีเซ็ตเมื่อเปลี่ยนคุณภาพ
- แก้: PoToken ใส่ timeout (สร้าง 30 วิ / ออก token 15 วิ), ไม่ใช้ generator ที่ปิดไปแล้วซ้ำ, ปิด WebView ที่ค้าง และแจ้ง error ให้คำขอที่รออยู่ แทนการหมุนค้างทั้งแอป

## v0.4.4
- แก้อาการโหลดช้าบางคลิป: ขอสตรีมจาก YouTube ทีละไม่เกิน 10 MB แทนคำขอแบบไม่มีจุดสิ้นสุด

## v0.4.3

## v0.4.1

## โครงสร้าง
- `core/` YtDownloader (OkHttp), YtRepo (search/stream/channel), Store (subs/history)
- `player/` PlayerHolder (ExoPlayer ตัวเดียวทั้งแอป), PlaybackService (MediaSession), datasource/YoutubeHttpDataSource (คัดจาก NewPipe)
- `potoken/` PoToken provider (คัดจาก NewPipe — จำเป็นให้ YouTube เล่นได้เสถียร)
- `ui/` Theme (Cyber), Components, Screens, PlayerScreen
